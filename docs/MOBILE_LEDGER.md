# 手机记账

首页「记一笔农活」和地块卡片上的同名按钮复用 `LedgerWorkspace`，新增和编辑使用同一份校验与类型字段处理，不改变接口。地块入口带入该地块；日期默认本机今天，今天唯一命中且起始日明确的茬次会带入。补录日期后重新按日期匹配，不沿用今天的茬次；重叠或开始日未填时提示明确选择，允许未归茬。编辑保留已有归茬选择，日期越界时提示并由服务端拒绝，用户可选择历史茬次或未归茬。

地块、日期和作业类型是基本信息，费用、用量、投入品、作业说明及采收产量/单价均可留空，之后编辑补齐。快速入口将用量、作物覆盖值和说明放入可展开的选填区；来自待办且已有说明时展开供本人核对。手机端常用类型用可触控的快捷按钮，桌面保留原下拉选择；切换类型清除不适用的投入品、间隔期和收入字段，并清空不同作业含义的用量。费用适用于所有类型，切换时保留当前本人填写值。金额为零与未填写仍分别处理。

一次保存后清空用量、费用、投入品、间隔期、产量、单价和说明；当前表单的类型、地块及日期可继续修改使用。重新从快速入口打开时使用今天及空数值，不带入上一笔的费用或产量。当前不保存常用单位和跨页面的最近选择。

## 未保存保护与账号边界

业务草稿仅保存在当前页面的 React 内存中，不写 localStorage、sessionStorage、IndexedDB 或服务器。切换功能、取消编辑/记账、打开另一笔编辑、从统计追溯返回、退出或重新加载演示资料会先检查未保存状态；可继续填写或明确放弃。退出或换账号后表单卸载，不保留上一账号的业务内容。地块、茬次和待办读取结果绑定账号，异步写入及刷新回调核对发起账号，退出或切换后丢弃旧响应，避免旧地块进入下一账号的新表单。访客保存为正式账号仍为同一个用户 ID，继续保留当前页面状态。

刷新和关闭页面使用浏览器原生离开提示。浏览器是否显示原生提示受其规则限制，手机强制关闭进程、断电或刷新后主动放弃会丢失尚未保存内容，当前没有持久草稿恢复能力。页面不承诺自动保存。

保存期间锁定表单并阻止离开，避免同次提交混入后续输入；成功有明确反馈，更新地块计数与相关统计。失败保留输入和提交标识，由用户检查网络后主动重试。复用服务端 `submission_id`：请求已经写入但响应丢失时，原样重试仍只创建同一笔；若修改了已经保存的提交内容，服务端返回冲突，请先核对台账再编辑。编辑重试更新原记录 ID。

没有 Service Worker、后台离线队列或自动重试；网络恢复不自行创建农事记录。

## 手机与桌面

390px 下使用单列输入、类型快捷按钮、数字键盘提示和至少 44px 的主要触控控件，保存操作留在表单底部可见区域。记账弹层锁定背景滚动，提供焦点约束、Esc 取消保护与关闭后焦点返回。桌面保留双列输入、下拉选项和表格；手机收支继续用同一数据来源的茬次卡片，避免横向读长表。

本次不增加依赖、不修改数据库结构、不迁移或复制业务数据。自动化浏览器验证不能替代真实手机浏览器及软键盘设备验证。
