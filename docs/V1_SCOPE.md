# V1.0 正式范围

本文冻结 Git 标签 `v1.0.0`（Commit `b952778`）的正式产品范围。当前未提交工作区中的后续工程增强不自动进入 V1.0。

## V1.0 正式包含

- 用户注册、登录、访客登录、退出和个人显示名称设置。
- 农技问答，会话创建、列表、详情、重命名和删除。
- 消息保存、乐观显示、失败恢复、幂等处理、会话分页和长会话游标分页。
- 田间图片上传校验与初步诊断。
- 根据天气、地块和作物阶段生成今日农活建议。
- 豆包/Ark 系统模型配置，以及无真实 Key 时的本地演示模式。
- SQLite 单机存储、`PRAGMA user_version=1` 迁移、WAL、事务和索引。
- 密码哈希、随机 Token、Token 摘要存储、过期与撤销。
- Bearer 认证、前端 localStorage Token 兼容流程。
- CORS、请求限流、输入长度限制、请求体限制、上传限制、安全响应头、请求 ID 和日志脱敏。
- liveness、readiness、数据库备份恢复、CI、发布候选打包和发布演练工具。

## V1.0 明确不包含

- PostgreSQL、Redis、Alembic 或 SQLite 到 PostgreSQL 迁移工具。
- Docker、Docker Compose、Nginx、自动 HTTPS 或多实例部署。
- 公网商业 SaaS、多租户、组织空间、套餐、计费或支付。
- 管理员、RBAC、用户禁用、审计后台或完整管理员后台。
- 用户自带 API Key、API Key 加密保存、任意 Base URL 或 Provider Adapter。
- Cookie 会话和 CSRF 防护；这些属于标签之后的当前工作区增强。
- metrics、JSON 结构化日志、Token 用量和调用成本统计。

只有在代码、自动化测试、真实运行验证和文档全部完成后，能力才能从“不包含”移出。

## 适用范围

- Windows 本地运行和单机部署。
- 同一局域网内的小规模受控试用。
- 课程、答辩、软著、作品集和产品演示。
- 农场、合作社或农业服务小团队的流程验证。

## 已知限制

- SQLite 不能由多个后端实例共享，Schema 不支持自动降级。
- 默认演示模式返回固定内容，不是真实 AI 判断。
- 系统模型需要管理员提供豆包/Ark Key，V1.0 没有用户级 Key 管理。
- Bearer Token 由前端 localStorage 保存，需防范浏览器脚本注入风险。
- 进程内限流不适用于多实例；日志不是 JSON，未接入集中监控。
- 图片诊断仅供初步参考，不能替代现场调查、产品标签或专业人员意见。
- 没有公网 HTTPS、持久化云数据库和多租户隔离，不适合直接公开运营。
