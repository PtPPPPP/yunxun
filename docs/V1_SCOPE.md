# 当前功能范围（未发布工作区）

截至 2026-10-19，机器版本仍为 `1.0.0`，页面为 `V1.0.0`，数据库 Schema 12。默认全称「云寻智慧农业工作台软件」，简称「云寻」；本轮不确定新的申报版本，不擅自更名。与历史同版本号的 AI 交付快照已有重大差异，不能混用材料。

## 当前提供

- 注册/登录/访客/退出、访客原地保存正式账号、资料修改、验证原密码改密、本人保管的一次性恢复码及可信部署者本机恢复。
- 默认首页、三步首次引导、主动加载并标识的访客演示；真实账号默认空数据。
- 地块档案和历史茬次，第一茬随地块创建，真实日历和起止关系校验，一块地仅一茬进行中。
- 农事台账新增/编辑、费用及采收产量/单价、历史归茬/未归茬、地块/茬次/类型/日期筛选和游标分页。
- 待办安排、完成/重开、杂事及关联地块；完成后由用户确认记账，取消/失败不撤销完成。
- 手机快速入口、按类型展示字段、失败保留内容、防重复、未保存保护。桌面保留表格和键盘操作。
- 每茬已记录收支差额、亩均指标、历史及作业年度筛选、缺失费用与不完整采收提示、组成记录追溯。
- 全部筛选台账及单茬收支 CSV，缺失留空、中文编码和文本公式防护。
- 地块/台账软删除、本人回收站、关联恢复、冲突拒绝及最终确认后的物理清理。
- 按登记施药日和输入间隔期取最晚日期；手工输入天气、墒情等后由本机规则生成建议与保存历史。
- SQLite、向前迁移、Cookie/CSRF 与兼容 Bearer、安全错误和请求 ID、运维数据库备份恢复工具。

## 计算和数据边界

收支差额 = 已记录收入 − 已记录支出，不等于完整经营利润。采收收入不完整时提示待补录；年度依据作业日期，跨年茬次不按开始年份整体归入。亩均按地块当前登记面积计算。登记提醒不验证真实产品标签或实际采收合规。

草稿仅页面内存，无持久草稿或后台离线同步。回收站保留至主动最终删除，没有自动清理，只恢复当前软删除资料。CSV 不能替代整库备份。待办单独删除和茬次删除不在回收站范围。

## 排除或尚未验证

不提供 AI 问答、图片诊断、外部模型/API Key、自动天气抓取、农资库存、短信/邮件、推送、复杂历史系统、管理员网页、付费服务。未实现 PostgreSQL/Redis 业务接入、容器和公网多实例 SaaS。

本轮是 Windows 本机与临时数据库验收，不能作为生产部署、真实手机软键盘、大容量压力或实际灾难恢复演练的替代。逐项状态见 [PROJECT_STATUS.md](PROJECT_STATUS.md) 和 [整体验收记录](acceptance/current-2026-10-19/README.md)。
