# 仍需申请人亲自确认的法律事实字段

以下内容不能仅根据源码判断，申请人或权利人应在正式提交前逐项确认：

1. 著作权人/申请人的法定名称、证件类型、证件号码、统一社会信用代码、住所地和联系人信息。
2. 软件开发方式是独立开发、合作开发、委托开发还是其他方式，并确认相应合同或权属文件。
3. 当前申请表填写的开发完成日期 `2026年7月12日` 是否符合真实开发完成事实。
4. 软件是否已经公开发表；如已发表，当前首次发表日期 `2026年7月12日` 是否真实准确。
5. 当前首次发表地点 `北京市昌平区` 是否为真实首次发表地点。
6. 软件权利取得方式、权利范围以及是否存在转让、继承、职务开发或共同著作权情形。
7. 软件全称“云寻智慧农业AI工作台软件”和简称“云寻AI”是否存在在先登记、商标或其他权利冲突。
8. 申请人提交给代理机构的签章、授权委托、身份证明和真实性声明是否完整有效。
9. 申报平台最终选择的软件分类、技术特点标签及发表状态是否与申请人真实情况一致。

在上述字段得到申请人明确确认前，不应把材料状态表述为“已完成法律事实核验”。
