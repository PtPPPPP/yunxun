# 功能说明草稿（当前工作区）

当前代码名称：云寻智慧农业工作台软件；简称：云寻；机器版本：1.0.0；页面：V1.0.0；数据库：Schema 12。以上是代码事实，最终申报名称和版本见待确认事项，不填申请主体或法定日期。

## 软件目的与环境

面向农户、合作社及基层农技人员，围绕地块和每一茬记录实际农活、安排待办、核对已记录收支，并按用户填写的现场条件生成本机规则建议。FastAPI 后端、React/Vite 浏览器界面、SQLite 单机数据库；本轮在 Windows 本机 Chromium 和 390px 浏览器视口验收，不代表所有手机或生产环境验收。

## 模块和操作

1. **身份与账户保存**：可注册、登录或使用访客。新用户默认首页，真实注册数据为空。访客可设置正式用户名、密码与显示名，保留原用户 ID 及地块、茬次、台账、待办、建议和来源关联；退出后用新凭据登录。历史账号不按名称前缀授予访客权限。
2. **账号安全**：正式用户验证原密码后改密；可自愿生成本人离线保管的一次性高熵恢复码，生成时仅展示一次，服务端仅存摘要。换码、使用、改密或重置使旧恢复码失效，改密/重置退出全部会话。密码和码都丢失时，仅可信部署者核验身份后通过本机交互命令辅助；不能核验则不能恢复，不提供公开信息直接重置。
3. **首次使用与演示**：引导登记第一块地、建立第一茬、记第一笔农活，允许跳过和继续。完成状态从实际业务数据核对；登记地块已创建第一茬，不重复建立。访客可选加载带演示标识的示例，重复加载不重复，清理仅处理演示并保护自己新增数据；不冒充真实收益。
4. **首页与待办**：首页显示本人登记的今日/逾期待办、相关地块和真实计数，提供快速记账；没有地块或待办时给出下一步入口。待办可关联地块或作为杂事，支持完成与重开。完成后由用户选择是否记账，取消或失败不撤销完成，只有确认保存才产生台账。
5. **地块与茬次**：登记面积（亩）、土壤、灌溉和备注，同时创建第一茬。作物与起止日属于茬次，支持结束本茬、开始新茬及历史查看。一块地同时最多一茬进行中，冲突明确返回，不覆盖已有数据；日期按真实日历和先后关系校验。
6. **农事台账**：按日期、地块、茬次记录播种、施肥、打药、灌溉、除草、采收和其他，新增和编辑共用表单。类型显示适用字段，费用、用量等可留空后补。补录按日期唯一匹配历史茬次；歧义须明确选择，允许未归茬，指定茬次须同属本人地块且日期适用。可按日期、地块、茬次、类型等筛选及翻页。保存期间锁定、失败保留内容、同次新增重试防重复；不会静默复制上一笔费用或产量。
7. **每茬收支与追溯**：已记录收支差额=已记录收入−已记录支出。费用未填与 0 元区别显示；采收收入只包含产量与单价完整的记录，缺失单列提示。按地块、历史茬次、作业年度及真实/演示来源查看；年度按作业日期，跨年不重复。单茬呈现起止、面积、次数、费用、产量、收入、差额及亩均，点击金额或缺失数量查看组成台账并可编辑，返回保留筛选。未知人工、地租等不自动包含。
8. **CSV 导出**：导出台账全部匹配页、单茬收支汇总及明细；包含可读地块/作物/茬次/日期/类型/用量和适用金额，单位明确、NULL 留空、UTF-8 BOM 与特殊字符转义，文本公式前缀防护。本人范围、下载进度与错误重试；无长期导出文件存储。CSV 用于分析留档，不是整库恢复备份。
9. **删除保护**：删除地块前核对茬次、全部台账、全部待办（含完成）。地块和台账进本人回收站，正常列表/计数/统计/建议输入排除；恢复保留原关联，先前单独删除台账仍须单独恢复。恢复冲突明确处理。保留至主动最终删除，无自动清理；最终清理二次确认，不可在回收站重建。历史硬删除无法凭空恢复，运维整库备份另行负责。
10. **本机建议与登记提醒**：用户填写作物、生长期、天气和墒情，本机规则给出农活建议并保留历史，可按需转为待办。登记施药提醒取同地块相关记录的最晚日期，不因短间隔或换茬提前解除，只核对登记输入算术，具体标签与实际合规由使用者另行确认。
11. **手机、帮助与关于**：手机提供首屏/地块快速入口、作业按钮、选填区、触控输入、保存反馈、离开确认和茬次收支卡片；桌面保留表格与键盘。帮助说明真实能力与恢复边界，关于显示代码配置名称与版本。草稿仅当前页面内存，不跨账号保留；无持久草稿、离线队列和后台自动保存。
