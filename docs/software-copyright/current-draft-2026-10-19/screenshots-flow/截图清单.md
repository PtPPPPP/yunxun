# 云寻智慧农业工作台软件界面截图与功能说明

软件版本：V1.0.0。共22张截图，按实际使用顺序从登录到退出排列。所有地块、账号、金额及产量均为合成样例。

对应源码文件：../source-code/yunxun-project-source-code-current.docx。以下源码页码按文档页首编号，源码70个文件的哈希与本次运行代码全部一致。

[查看原始截图](01-用户登录.png)

对应源码：frontend/src/components/FarmRecordForm.tsx（源码材料第100—109页）；frontend/src/App.tsx（源码材料第79—87页）。

对应源码：frontend/src/components/FarmRecordForm.tsx（源码材料第100—109页）；backend/app/services/farm.py（源码材料第20—28页）。
