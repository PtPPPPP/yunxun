# 路线图

路线图只描述未来目标和进入条件，不代表功能已经实现。

## V1.1：体验与软著展示完善

目标：完成真实页面截图、软著交付检查和关键用户流程文案验收。

前置条件：V1.0 范围、源码材料、版本和测试结果一致。

## V1.2：安全 BYOK

目标：把当前默认关闭的 BYOK 工程实现升级为正式能力。

前置条件：至少完成 OpenAI 与 DeepSeek 的受控真实冒烟、Provider 错误矩阵、主密钥轮换方案、备份恢复验证和安全评审。任意 Base URL 仍只允许管理员白名单，不开放无限制地址。

## V2.0：公网单租户 Beta

目标：支持一个运营主体的公网受控试用。

前置条件：HTTPS、持久化数据库、集中限流、监控告警、安全审计、备份恢复和容量验证全部完成。

## Future：商业 SaaS

目标：多租户、组织空间、RBAC、套餐、计费和支付。

前置条件：先取得单租户真实客户、稳定运维和合规证据，再决定是否建设；当前不开发。
